## Agentic Architectures Design

This repository is a collection of state-of-the-art agentic design, from single-agent enhancements to complex, collaborative, and self-improving systems, built with LangChain and LangGraph. All the architectures are implemented end-to-end in a runnable Jupyter notebook. Most notebooks feature a robust LLM-as-a-Judge pattern to provide quantitative, objective feedback on an agent's performance.
